# Kubernetes Course Tasks

This repository contains practical Kubernetes tasks completed as part of the **MLOps MENA Community Kubernetes Course**.

## Tasks

### Task 1: Multi-Container Pods (Init Container & Sidecar)

Demonstrates how to deploy a multi-container Nginx application using Kubernetes Init Containers and Sidecar Containers.

The task covers:

- Init Container execution and lifecycle.
- Multi-container Pod architecture.
- Shared process namespace.
- Sidecar container interaction using `/proc`.
- Nginx timestamp updates.
- Kubernetes Deployments and Services.
- Rolling Updates, failure handling, and recovery.
